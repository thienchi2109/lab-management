# Hướng dẫn Viewer

## Mục tiêu

Viewer xem dữ liệu vận hành, dashboard và export mà không chỉnh sửa mẫu hoặc cấu
hình.

## Xem dashboard

1. Đăng nhập bằng tài khoản Viewer.
2. Mở `Tổng quan`.
3. Kiểm tra số mẫu nhận, KIT đang hoạt động, kết quả PCR và danh sách mẫu gần
   đây.
4. Chọn `Xem analytics` để mở báo cáo chi tiết nếu cần.

## Xem bảng mẫu

1. Mở `Mẫu xét nghiệm`.
2. Dùng tìm kiếm, bộ lọc trạng thái, thanh toán và sắp xếp.
3. Dùng tùy chọn cột để ẩn hiện thông tin cần xem.
4. Mở trang kết quả để xem kết quả và ảnh minh chứng.

## Export dữ liệu

1. Mở `Mẫu xét nghiệm`.
2. Chọn định dạng `CSV` hoặc `XLSX`.
3. Chọn `Export mẫu` hoặc `Export kết quả`.
4. Nếu file quá lớn, thu hẹp bộ lọc rồi thử lại.

## Giới hạn quyền

Viewer không được tạo mẫu, sửa mẫu, nhập kết quả, upload ảnh, sửa cấu hình hoặc
quản lý người dùng.
